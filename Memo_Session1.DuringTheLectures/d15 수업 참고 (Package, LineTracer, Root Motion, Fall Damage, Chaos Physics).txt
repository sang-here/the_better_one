-line tracer transform 생성하기
스켈렉탈 메쉬에서 line tracer의 출발 타겟 위치 파악(ex, spine 03) - 마우스 우클릭 - copy bone name
mesh 가져와서 get socket location에 bone name 붙여넣기 - start 값에 월드위치를 line tacer에 연결
end 값에는 - gey socket rotation - get right vector(단위 벡터라 길이가 1이라 원하는 값 곱해줘야 함) (mesh 앞 방향이 green = right임) 
vector 방향
forward vector = red
right vector  = green
up vector  =blue

- line trace 설정
trace complex는 complex 콜리전을 기준으로 계산 (엄밀)

draw debug time(to see debugging visually)
for one frame = 매 프레임 마다
for duration / draw time = duration time
persistent = 지나간 곳에 전부 그려지고 저장됨
