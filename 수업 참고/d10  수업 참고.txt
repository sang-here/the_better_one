이주는 contents folfer to contents folder / 에셋에 연결된 것들도 자동으로 같이 이주해줌
스타트업 컨테츠를 수정하면, 이를 이주하면 충돌이 생길 수 있음. -> 플러그인
도구의 마무리 = 플러그인 -> 펩에다 올려다 팔 수도 있음

컨텐츠드로어 안 - 톱니바퀴 표시 - 플러그인 체크 - 엔진 폴더에서 저장된 플러그인 볼 수 있음
현재 언리얼에 제공된 플러그인들은 레전드 레거시들 모음임

<플러그인 생성 방법>
플러그인 - add - contents only - name - description ...  - creat - other 탭에 생김 - 에셋 넣고 - 다시 플러그인 other에서 꼭 패키지(포장하기)를 누르고 원하는 위치에 저장
<플러그인 저장 방법>
원하는 프로젝트 폴더 내에 Plugins 폴더르 만들어주고 생성된 플러그인 파일을 그대로 복붙하면 이동 저장됨
*이주는 컨텐츠 폴더 뿐아니라, 플러그인 폴더 내에 있는 컨텐츠 폴더에도 할 수 있음(플러그인 하나의 모듈, 하나의 작은 프로젝트임) - 방법: 자체 폴더내에 만들어 놓은 플러그인 안에 컨텐츠 폴더에 이주 후, 그 플러그인 패키징한 후 다시 그 자체를 다시 다른 프로젝트로 이동

플러그인의 에셋 사용시 무결성 유지하며 사용하는 것이 보통 아주 중요한 원칙이며, 이를 유지하는 방법은 상속받아 오는 것!, 내 컨텐츠에 새로 블루프린트 클래스 - 액터에서 모든 클래스에서 검색해서 카피본 생성 및 사용(원본은 건드리면 돌아갈 수 없소!!)
-상속 받은 에셋은 자체 코드가 제로이고, 상속받은 코드(from parent class)는 고정형으로 고칠 수 없음
-상속 받은 에셋의 코드를 1이라도 생성하는 순간. 부모 클래스로부터 상속 받은 코드는 중지됨.
- 자식 코드와 부모 코드를 상속된 에셋에서 동시에 유지하는 방법은, 이벤트에서 우클릭 and add call to parent function으로 함수로 부모의 코드 불러오기
- 부모 코드를 상속 에셋에서 수정하려면서 쓰려면 부모 코드 복붙 or override 함수 이용 불러내서 collapse it then edit it
